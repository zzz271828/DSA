Quick Complexity Reference

Sorting

  • Selection Sort O(n²)
  • Insertion Sort O(n²) / O(n)*
  • Merge Sort O(n log n)
  • Heapsort O(n log n)
  • Quicksort (avg) O(n log n)
  • Counting Sort O(n + k)
  • Radix Sort O(d(n + k))

Graph Traversal & Paths

  • BFS / DFS O(V + E)
  • Dijkstra (heap) O((V+E) log V)
  • Bellman-Ford O(VE)
  • Floyd-Warshall O(V³)
  • Topological Sort O(V + E)
  • Critical Path O(V + E)

Greedy & MST

  • Prim's (heap) O((V+E) log V)
  • Kruskal's O(E log E)
  • Union-Find O(α(n)) ≈ O(1)

Selection

  • Quickselect (avg) O(n)
  • Quickselect (worst) O(n²)
  • Median of Medians O(n)
  • Find min + max ≈1.5n cmps

Search Trees

  • BST (balanced) O(log n)
  • AVL height ≤1.44 log n
  • RB-Tree height ≤2 log n
  • 2-3 Tree height Θ(log n)

String Structures

  • Trie insert/lookup O(|s|)
  • Suffix tree build O(n)
  • Pattern matching O(|P|)
  • Longest rep. substr O(n)

Dynamic Programming

  • Knapsack (0-1) O(nW)
  • Edit Distance O(mn)
  • Matrix Chain O(n³)
  • Coin Change O(n·|coins|)

Network Flow

  • Ford-Fulkerson O(E·|f*|)
  • Edmonds-Karp O(VE²)
  • Bipartite Match O(VE)
  • Circulation O(VE²)
Algorithm Design Paradigms
Divide & Conquer
Break into subproblems, solve recursively, combine. Key: recurrence relations.
Karatsuba · Merge Sort · Count Inversions · Quicksort
Greedy
Locally optimal choices. Requires: greedy choice property + optimal substructure.
Dijkstra · Prim's · Kruskal's · Heapsort
Dynamic Programming
Cache overlapping subproblem results. Top-down (memo) or bottom-up (table).
Knapsack · Edit Distance · Floyd-Warshall · Bellman-Ford
Network Flow
Model as flow network, reduce to max-flow. Incredibly powerful for combinatorial problems.
Ford-Fulkerson · Matching · Circulation · Scheduling
